🌾 About AgriPredict & Protect

AgriPredict & Protect is an AI-powered smart agriculture system designed to help farmers make better decisions using Machine Learning technologie. This system focuses on Crop Yield Prediction and Crop Recommendation using soil and weather data.

📊 Crop Yield Prediction System

This module predicts crop production based on soil nutrients and environmental factors such as Nitrogen (N), Phosphorus (P), Potassium (K), temperature, humidity, rainfall, and pH value.

  • ✔ Machine Learning based prediction
  • ✔ Output in production units (tons/kg)
  • ✔ Helps farmers choose best crop
  • ✔ Supports sustainable farming

🍃 Crop Recommendation System

A Crop Recommendation system which Predict the crops based on soil and environmental to help farmers make informed decisions about crop selection and management

  • ✔ Crop recommendations
  • ✔ work on real life data
  • ✔ Soil nutrient analysis
  • ✔ Weather data analysis
