Crop Recommended System

About Crop Recommended Systemn

Crop Recommended System is a smart agricultural solution that helps farmers and agricultural organizations estimate suitable crop before harvest using modern data-driven techniques.

The system analyzes soil quality, rainfall, temperature, humidity, to provide accurate suitable crop. Using Machine Learning and Data Analytics, it enables better planning, reduces risks, and improves farm productivity.

🌱 Features

It supports 15 different crop types, including banana, chickpea, coco nut, coffee, cotton, jute, lentil, maize, mango, mothbeans, muskmelon, orange, papaya, pigeonpeas, and watermelon. By analyzing key agricultural parameters such as soil nutrients (N, P, K), temperature, humidity, pH level, rainfall ,the system predicts suitable crop accurately.
