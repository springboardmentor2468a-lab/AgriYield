AgriYield Predictor

Project Overview:
AgriYield Predictor is an AI-powered agricultural decision-support system developed as part
of my internship. The project integrates machine learning models with a Flask-based web
application to assist farmers and agricultural planners in making data-driven crop decisions.

The system performs two key tasks:
1. Predicts the expected crop yield (kg per hectare) for a selected crop.
2. Recommends the Top 5 most suitable crops based on soil nutrients and climate conditions.

Inputs include Nitrogen, Phosphorus, Potassium, temperature, humidity, soil pH, and rainfall.
All inputs are provided through range-based sliders to ensure realistic agricultural values
and improved user experience.

Key Features:
- Machine Learning–based crop yield prediction
- Crop suitability recommendation (Top 5 crops)
- Dark-gradient, professional user interface
- Range-based sliders for soil and climate inputs
- Clean visual hierarchy and responsive design
- Mentor-friendly and industry-oriented frontend
- Seamless integration of ML models with Flask backend
