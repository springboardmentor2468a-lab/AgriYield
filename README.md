## 📖 About The Project

**AI AgriYield Predictor** is an advanced Machine Learning web application designed to help farmers and agricultural planners estimate crop production potential. By analyzing key soil nutrients (N, P, K) and environmental conditions (Temperature, Humidity, pH, Rainfall), the system provides accurate yield predictions and crop recommendations.

This project was developed during the **Infosys Springboard Virtual Internship 6.0**.

### 🌟 Key Features

* **🌾 Yield Prediction:** Estimates crop yield in **kg/ha** using Random Forest Regression.
* **💡 Smart Crop Recommendation:** Suggests the best suitable crops for specific soil conditions.
* **📊 Interactive Dashboard:** Visualizes dataset trends and agricultural insights.
* **🎨 Modern UI:** Features a Glassmorphism design with **Dark/Light mode** toggle.
* **🧪 Simulation Mode:** Allows real-time parameter tuning to see how changes affect yield.
