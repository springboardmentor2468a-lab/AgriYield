# 🌾 AgriYield Predictor

An AI-powered web application that predicts agricultural crop yield using soil, weather, and environmental data.

---

## 🚀 Features

- 🌱 Crop yield prediction using Machine Learning
- 📊 Interactive dashboard with charts & analytics
- 🔐 Secure authentication (JWT)
- 💳 Subscription-based payments (Razorpay)
- 🌦️ Real-time weather data integration
- 📁 CSV export of predictions
- 🛠️ Admin panel for monitoring users & predictions
- 📱 Fully responsive (mobile-first UI)

---

## 🧠 Tech Stack

### Frontend
- Next.js 14 (App Router)
- Tailwind CSS
- Chart.js

### Backend
- Python (Flask)
- Scikit-learn
- JWT Authentication

### Database
- MongoDB Atlas

### APIs
- OpenWeather API
- Razorpay Payments API

### Deployment
- Frontend: Vercel
- Backend: Render

---

## ⚙️ How It Works

1. User signs up / logs in
2. Inputs soil & environmental parameters
3. Weather data is auto-fetched via API
4. ML model predicts yield with confidence score
5. Results are stored and visualized on dashboard
6. Users can export predictions as CSV
